For 'where/how is X done' questions about code, search with semble first, through codemode: `await tools.mcp__semble__search({ query: "<behaviour or name>", repo: "<the absolute cwd>", top_k: 5 })`, then jump to the returned file:line. Use rg only for exact-string sweeps.
Once the task is about a known symbol (its body, its callers, a rename, a file's outline), use serena through codemode instead of reading or grepping whole files: `tools.mcp__serena__find_symbol({ name_path_pattern, relative_path, include_body: true })`, `find_referencing_symbols({ name_path, relative_path })`, `get_symbols_overview({ relative_path })`. Not for docs, config, shell scripts, or languages without a serena language server (`.serena/project.yml`): read with offset/limit there.
